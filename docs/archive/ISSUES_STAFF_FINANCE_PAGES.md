## 🔴 Актуальные проблемы

### 1. Ошибка "Бизнес не найден" на `/dashboard/staff/[id]/finance` ✅ ИСПРАВЛЕНО

**Описание**: 
Страница показывала сообщение "Нет доступа к кабинету" вместо контента финансов сотрудника.

**Причины**:
- Функция `getBizContextForManagers()` использовала anon key, который подчиняется RLS политикам
- RLS политики блокировали доступ к таблицам `user_roles` и `businesses`
- У пользователя могли отсутствовать необходимые права доступа

**Что исправлено**:
- ✅ Использование service role key для обхода RLS при проверке доступа к бизнесу
- ✅ Улучшена логика поиска бизнеса - учитываются роли с `biz_id=null` (глобальные роли)
- ✅ Приоритет ролей: сначала роли с конкретным `biz_id`, затем глобальные
- ✅ Улучшен компонент `DashboardLayoutClient` с более понятными сообщениями об ошибках
- ✅ Добавлены детальные инструкции по решению проблемы
- ✅ Добавлена диагностическая информация для разработчиков (в dev режиме)

**Технические детали**:
- Функция `getBizContextForManagers()` теперь создает service client для проверки доступа
- Service client обходит RLS политики, что позволяет корректно проверять права пользователя
- Логика поиска бизнеса: super_admin → user_roles (с приоритетом biz_id) → owner_id

**Приоритет**: ✅ РЕШЕНО
