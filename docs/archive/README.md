# Архив документов

Здесь хранятся документы, которые больше не являются основным источником правды, но сохранены для истории и справки.

- **REFACTOR_TASKS.md** — задачи рефакторинга (большинство выполнено). Живой бэклог: [FUTURE_IMPROVEMENTS_TASKS.md](../../FUTURE_IMPROVEMENTS_TASKS.md).
- **IMPROVEMENT_TASKS.md** — дорожная карта улучшений (эволюционный план). Текущие задачи: [FUTURE_IMPROVEMENTS_TASKS.md](../../FUTURE_IMPROVEMENTS_TASKS.md).
- **TASKS.md** — список задач по улучшению Kezek. Актуальный бэклог: [FUTURE_IMPROVEMENTS_TASKS.md](../../FUTURE_IMPROVEMENTS_TASKS.md).
- **CONSOLE_LOG_MIGRATION.md**, **CONSOLE_LOG_MIGRATION_PROGRESS.md**, **MIGRATION_SUMMARY.md** — история миграции с console.log на безопасное логирование (миграция завершена). Актуальные правила: [LOGGING_POLICY.md](../../apps/web/src/lib/LOGGING_POLICY.md).
- **ISSUES_STAFF_FINANCE_PAGES.md**, **COMPARISON_STAFF_FINANCE_PAGES.md** — проблемы и сравнение страниц финансов сотрудников (большинство решено; для истории).
