# Первый запуск: маршрут по документации

Статус: действующий указатель, обновлён 2026-11-01. Аудитория: новый разработчик. Выполненный запуск на чистой машине этим документом не подтверждён.

Единственная инструкция установки — [GETTING_STARTED](../GETTING_STARTED.md). Здесь нет второго набора команд или альтернативных значений окружения.

| Шаг | Где выполнить подготовку | Ожидаемый результат |
| --- | --- | --- |
| Определить задачу и допустимую среду | [Состояние проекта](PROJECT_STATUS.md), [онбординг](ONBOARDING.md) | Известно, нужны ли запуск, доступ к данным и интеграции |
| Подготовить Node, pnpm и зависимости | [Требования и установка](../GETTING_STARTED.md#требования-и-установка) | Версии соответствуют manifest/lockfile, установка не меняет зависимости |
| Получить схему и доступ к dev-данным | [База данных](../GETTING_STARTED.md#база-данных-обязательная-зависимость) | Есть подготовленная среда либо проверенный baseline; пустая БД сама не восстанавливается из неполной цепочки миграций |
| Задать конфигурацию | [Переменные окружения](../GETTING_STARTED.md#переменные-окружения) | Web/mobile указывают на согласованную среду; существующие env-файлы сохранены |
| Запустить выбранное приложение | [Первый запуск](../GETTING_STARTED.md#первый-запуск-для-разрешённой-задачи) | Известны текущий процесс и адрес; mobile-устройству доступен dev API |
| Проверить выбранный сценарий | [Руководство проверок](../TESTING_GUIDE.md), [контракт API](../API_DOCUMENTATION.md) | Зафиксированы среда, ожидаемый результат и фактическое наблюдение |

Первый экран и HTTP 200 не подтверждают работу auth, RLS, бронирования или финансов. Swagger имеет [известные ограничения](../SWAGGER_SETUP.md), а наличие Bearer header не заменяет cookie session в маршруте, который читает только cookies.

Для первой брони нужны согласованные пользователь, бизнес, сотрудник, услуга и свободное время, а также решение по внешним уведомлениям. Это запись данных, а не универсальный read-only smoke. Сценарий выбирается по [функциональной модели](../SYSTEM_FEATURES_DOCUMENTATION.md); запрещённые старым WEB workflow действия не возобновляются чтением этой страницы.

При ошибке используйте [диагностику запуска](../GETTING_STARTED.md#если-запуск-не-удался). Локальный адрес не гарантирует изоляцию от удалённой БД; production API не является значением по умолчанию для нового mobile-стенда.
