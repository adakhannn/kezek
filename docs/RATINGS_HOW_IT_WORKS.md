## Как считается рейтинг в Kezek

Этот документ предназначен для владельцев и менеджеров. Он описывает, из чего складывается рейтинг сотрудников, филиалов и бизнеса, и что можно сделать, чтобы его улучшить.

### 1. Общая идея

- **Рейтинг считается по данным за последние N дней** — по умолчанию 30. Это "скользящее окно": каждый день старые дни выбывают, новые добавляются.
- Каждый день для сотрудника, филиала и бизнеса считаются **дневные метрики**. На их основе считается **дневной балл (0–100)**.
- Итоговый рейтинг — это **среднее по дневным баллам за окно** с учётом настроек формулы.

Рейтинги используются для сортировки сотрудников, филиалов и бизнесов в выдаче и видят их как владельцы, так и клиенты.

### 2. Компоненты рейтинга сотрудника

Рейтинг сотрудника состоит из четырёх компонент (вес каждой настраивается суперадмином или, при необходимости, отдельно для бизнеса):

- **Отзывы клиентов**  
  Учитываются:
  - средняя оценка по отзывам за период (1–5);
  - количество отзывов (бонус за большее число честных отзывов);
  - отсутствие отзывов при наличии клиентов даёт мягкий штраф.

- **Продуктивность (количество клиентов)**  
  Смотрим, сколько уникальных клиентов обслужил мастер и сравниваем это с **средним по филиалу** за тот же период. Выше среднего → ближе к 100, ниже → пропорционально меньше.

- **Возвращаемость клиентов**  
  Доля клиентов, которые **вернулись 2+ раза**. Чем выше возвращаемость, тем выше компонент "лояльности".

- **Дисциплина**  
  Учитываются:
  - суммарные **минуты опозданий** и доля смен с опозданием;
  - количество бронирований со статусами **no-show** и **cancelled**.  
  Опоздания, no‑show и частые отмены снижают дисциплинарный под‑скор, но при единичных случаях влияние умеренное.

Каждая компонента сначала нормализуется в диапазон **0–100**, а затем умножается на свой вес.

### 3. Веса и окно по дням

Глобально по платформе (или отдельно для бизнеса) задаются веса:

- **Отзывы** — сколько % рейтинга даёт оценка клиентов.
- **Продуктивность** — доля влияния количества клиентов.
- **Возвращаемость** — сколько даёт доля "повторных" клиентов.
- **Дисциплина** — насколько сильно опоздания и no‑show влияют на итог.

Сумма весов всегда **= 100%**. Также задаётся **окно по дням** (например, 30), за которое берутся дневные метрики для усреднения.

### 4. Порог "достаточно данных"

Чтобы рейтинг был стабильным и не "скакал" от пары записей, система вводит минимальные пороги:

- минимум **N дней с активностью** (по умолчанию 5);
- минимум **M клиентов** за окно (по умолчанию 10);
- минимум **K смен** (по умолчанию 3).

Если пороги не выполнены, **числовой рейтинг не показывается** — вместо этого в интерфейсе вы увидите надпись вроде:

> "Недостаточно данных для рейтинга"

Как только мастер накопит достаточно клиентов и смен, рейтинг появится автоматически после ночного пересчёта.

### 5. Рейтинг филиала и бизнеса

- **Филиал**:  
  Дневный балл филиала считается как **средний дневной балл сотрудников** филиала за день (с учётом их активных смен и дневных метрик). Итоговый рейтинг филиала за окно — среднее по дневным баллам.

- **Бизнес**:  
  Дневной балл бизнеса — **средний дневной балл филиалов**. Итоговый рейтинг бизнеса за окно — среднее по дневным баллам.

Если для филиала или бизнеса временно не удаётся посчитать рейтинг (например, нет данных по сотрудникам), система берёт **усреднённое значение по доступным дочерним сущностям** или аккуратный стартовый рейтинг.

### 6. Где посмотреть и как использовать

- В кабинете бизнеса (`/dashboard`) на главной странице отображается:
  - текущий рейтинг бизнеса;
  - активная формула (глобальная или своя для этого бизнеса);
  - веса компонентов и окно по дням.
- В админке (`/admin`) есть разделы для проверки здоровья рейтингов и отдельных проблемных сущностей.

### 7. Как улучшить рейтинг на практике

- Следить за **качеством сервиса и отзывами**:
  - мотивировать клиентов оставлять честные оценки,
  - оперативно реагировать на негатив.
- Работать над **заполняемостью графика**: стабильный поток клиентов важен для продуктивности.
- Уделять внимание **возвращаемости**:
  - напоминания клиентам,
  - программы лояльности, качественный первичный опыт.
- Контролировать **дисциплину**:
  - снижение опозданий,
  - минимизация no‑show и отмен через гибкое, но прозрачное правило отмены.

Система рейтингов не предназначена для "наказания", её цель — **подсветить сильные и слабые стороны** и помочь принимать управленческие решения на основе понятных метрик.
