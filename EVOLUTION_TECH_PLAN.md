# План эволюционных технических улучшений Kezek (архитектура, DX, мониторинг, mobile)

**Эволюционный план;** текущие задачи для спринтов — в **[FUTURE_IMPROVEMENTS_TASKS.md](FUTURE_IMPROVEMENTS_TASKS.md)**.

**Цель документа**: зафиксировать технические улучшения поверх уже стабильного прод‑состояния проекта — без «революций», с акцентом на:

- архитектуру доменов (бронь, промо, рейтинги, расписания);
- удобство разработки (DX) и процессы;
- дальнейшее развитие тестов и наблюдаемости;
- выравнивание web / mobile по возможностям и UX;
- управление жизненным циклом данных и безопасностью.

Каждый подпункт можно брать как отдельную маленькую задачу.
