# HTTP API Kezek

Статус: действующий справочник, сверка исходников завершена 1 ноября 2026. Метод: route → HTTP/service → schema/типы и связанные SQL, без запуска приложения. Runtime NOT_RUN.

## Найти маршрут

**[Полный каталог HTTP-маршрутов](docs/api/ROUTE_CATALOG.md)** автоматически строится из TypeScript exports, включая route.tsx, локальные re-export, /admin/api, /dashboard/api и callbacks вне /api. Для каждой явно экспортированной пары METHOD/path указан тематический контракт.

Каталог проверяет полноту сопоставления, а не доступность deployment или безопасность операции. Прямые обращения web/mobile к Supabase и RPC находятся за границей HTTP-каталога: [архитектура](PROJECT_DOCUMENTATION.md), [Supabase](supabase/README.md).

## Как читать контракт

- **По исходникам** означает, что описана цепочка в этом checkout. Схема и ACL удалённой БД, настройки провайдера и работа внешнего scheduler отдельно не установлены.
- **Нет limiter/auth в handler** — наблюдение кода, а не рекомендация оставить маршрут публичным. Наличие wrapper, layout или UUID не доказывает проверку всех вложенных связей.
- **HTTP 200 / ok:true** не гарантирует полноту составной операции. В нескольких текущих цепочках ошибки отдельных запросов подавляются, сохранение выполняется без ожидания или provider error находится внутри data.
- **GET** может иметь эффект записи: это отмечено в контрактах cron, notification-emails и отдельных диагностических потоков. Не использовать все GET как безвредный smoke.
- **OPEN** — статически обнаруженное ограничение. Ни одна такая запись не считается исправленной документацией; [инженерный реестр](docs/ENGINEERING_FINDINGS.md).
- Примеры содержат фиктивные данные. Команда или HTTP-описание не разрешает запуск против рабочих аккаунтов и production.

Общий формат helpers и реальные исключения: [ответы и ошибки](apps/web/src/lib/API_ERROR_FORMATS.md). Общие presets, доверенный ingress и fail-closed Redis: [RATE_LIMITING](RATE_LIMITING.md). Имена окружения: [ENV_GUIDE](ENV_GUIDE.md).

## OpenAPI и совместимость

[Swagger guide](SWAGGER_SETUP.md) описывает воспроизводимые offline OpenAPI/SDK artifacts. `/api/swagger.json` отдаёт OpenAPI object в корне. Полный AST inventory содержит все явные METHOD/path, а типизированный SDK — только четыре проверенные booking/shift операции; `inventory-only` не обещает схемы или отсутствие авторизации. Версия документа не является версией всего HTTP API.

Для изменения метода согласовать входы, статусы, envelope, авторизацию, побочные эффекты, повтор и потребителей. Новый endpoint создаётся по [HOWTO](apps/web/src/lib/HOWTO_NEW_API_ENDPOINT.md). Изменение денежной операции требует отдельно описанной атомарности и проверки; наличие имени atomic/safe не заменяет её.

## Сопровождение и проверка документации

1. При изменении route или связанного контракта обновить соответствующий тематический раздел.
2. Для каждой явно экспортированной операции поддерживать один комментарий `api-contract: METHOD /path`. Он учитывается проверкой полноты.
3. Сверить новые или изменённые исходники, затем из корня обновить каталоги:

```bash
node scripts/generate-api-catalog.mjs --write
node scripts/generate-docs-catalog.mjs --write
node scripts/check-doc-links.mjs
```

API-каталог хранит fingerprint routes и явно связанных из контрактов исходников. Его изменение требует повторной смысловой сверки, а не только обновления hash. Автоматический PASS подтверждает согласованность ссылок, JSON-примеров, каталогов и покрытия markers; он не выполняет запросы и не доказывает поведение приложения.
