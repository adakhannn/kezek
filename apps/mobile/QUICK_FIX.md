# Ошибка загрузки мобильного приложения

Статус: указатель, обновлён 1 ноября 2026.

Для `Failed to download remote update` сначала определить SDK, тип клиента и доступность dev-сервера по [руководству диагностики](TROUBLESHOOTING.md#разделить-причины). В нём же описаны условия выбора LAN/tunnel и работы с кэшем.

Прежняя последовательность «tunnel → очистить всё → переустановить зависимости» заменена диагностикой причины. Полезный результат — установленный слой отказа и воспроизводимый сценарий, а не количество перезапусков.
