# Учётная запись Expo

Статус: справочник, обновлён 1 ноября 2026. Учётная запись Expo и пользователь Kezek/Supabase — разные системы.

Локальная CLI поставляется с зависимостью `expo` в [package.json](package.json). Используйте её из workspace; глобальная установка отдельного `expo-cli` для проекта не требуется. [Expo CLI](https://docs.expo.dev/more/expo-cli/).

Для задачи, которой действительно нужен Expo account, из корня доступны команды:

```bash
pnpm -C apps/mobile exec expo whoami
pnpm -C apps/mobile exec expo login
```

Первая проверяет выбранную CLI-учётную запись, вторая запускает интерактивный вход. Действия выполняет владелец доступа; пароли и коды не записываются в документацию или логи.

Для некоторых вариантов Expo Go требуется одна учётная запись в CLI и на устройстве; условия зависят от версии клиента и платформы. Сверить сообщение клиента и [инструкцию Expo для устройства](https://docs.expo.dev/get-started/start-developing/). Вход в Expo не исправляет настройки API Kezek, вход пользователя или права Supabase.

Первый запуск описан в [GETTING_STARTED](../../GETTING_STARTED.md); сетевые ошибки — в [диагностике](TROUBLESHOOTING.md). Публикация, EAS build/update и изменение аккаунта проекта не входят автоматически в локальную настройку.
