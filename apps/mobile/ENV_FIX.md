# Если mobile не получает конфигурацию

Статус: указатель, обновлён 1 ноября 2026.

Сверить путь файла, нужные имена и потребителей по [ENV_GUIDE — Mobile](../../ENV_GUIDE.md#mobile), затем выбрать соответствующий симптом в [диагностике](TROUBLESHOOTING.md). Проверять наличие настроек без вывода секретов. Очистка кэша не является универсальным исправлением конфигурации.
