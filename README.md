# Kezek

Kezek — платформа записи клиентов и управления салонами: публичная запись, личный кабинет, кабинет бизнеса, рабочее место сотрудника и администрирование.

Монорепозиторий содержит Next.js web/API (`apps/web`), Expo / React Native (`apps/mobile`), общую доменную логику (`packages/core-domain`) и клиентские утилиты (`packages/shared-client`). Данные и авторизация используют Supabase.

## Статус

На 30 октября 2026 готовность к выпуску и предел нагрузки не подтверждены. Открытые риски и их источники: [инженерные проблемы](docs/ENGINEERING_FINDINGS.md). Текущий приоритет работы ведётся в [состоянии проекта](docs/PROJECT_STATUS.md).

Широкая автономная WEB-кампания закрыта, automation `kezek` остаётся PAUSED. Её ограничения и источники результатов собраны в [передаче WEB-кампании](docs/WEB_AGENT_HANDOFF.md).

Запуск требует согласованного окружения и схемы базы; ограничения восстановления чистой БД описаны в руководстве запуска. Исторические планы не являются текущей очередью работ.
