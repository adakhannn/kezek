# Kezek — Основные продукты для бизнесов

## Обзор

**Kezek** — это CRM-система для управления бизнесом в сфере услуг (салоны красоты, барбершопы, студии и т.д.). 

Система предлагает бизнесам **два основных продукта**:

1. **📅 Система бронирования** — управление записями клиентов
2. **💰 Финансовая система** — управление сменами и расчет зарплат сотрудников

---

## 1. 📅 Система бронирования

### Что это?

Полнофункциональная система онлайн-бронирования, которая позволяет клиентам записываться на услуги через веб-сайт или мобильное приложение.

### Основные возможности

#### Для бизнеса (Dashboard):
- **Календарь записей**: просмотр всех записей по дням, сотрудникам, филиалам
- **Управление статусами**: 
  - `hold` — ожидает подтверждения
  - `confirmed` — подтверждена
  - `paid` — выполнена (клиент пришел)
  - `cancelled` — отменена
  - `no_show` — клиент не пришел
- **Фильтрация**: по филиалам, сотрудникам, статусам, датам
- **Быстрая запись гостя**: создание записи без регистрации клиента
- **Управление расписанием**: настройка рабочих часов филиалов и сотрудников

#### Для клиентов:
- **Онлайн-бронирование**: выбор филиала, мастера, услуги и времени через веб-интерфейс
- **Личный кабинет**: просмотр своих записей, история посещений
- **Уведомления**: email, SMS, Telegram, WhatsApp напоминания о записях
- **Отзывы**: возможность оставить отзыв после посещения
- **Быстрая запись**: возможность записаться без регистрации (guest booking)

### Технические особенности

- **Умное расписание**: автоматический расчет свободных слотов с учетом:
  - Рабочих часов филиала
  - Рабочих часов сотрудника
  - Уже существующих записей
  - Длительности услуги
  - Временных переводов сотрудников между филиалами
- **Резервирование слотов**: временное резервирование (hold) на 2 минуты
- **Промоакции**: автоматическое применение акций при оплате
- **Мультиязычность**: поддержка RU/KY/EN для услуг и интерфейса

### Файлы и компоненты

```
apps/web/src/app/
├── b/[slug]/              # Публичная страница бронирования
│   ├── booking/           # Форма бронирования
│   └── view.tsx           # Основной компонент
├── booking/[id]/          # Страница просмотра брони
├── cabinet/bookings/      # Личный кабинет клиента
├── dashboard/bookings/    # Управление записями (для бизнеса)
└── staff/bookings/        # Записи сотрудника
```

### API Endpoints

- `/api/quick-hold` — быстрое резервирование слота
- `/api/quick-book-guest` — быстрая запись гостя
- `/api/bookings/[id]/cancel` — отмена записи
- `/api/public/bookings/` — публичные endpoints для бронирования

### База данных

- **Таблица `bookings`**: все записи клиентов
- **Таблица `working_hours`**: расписание филиалов и сотрудников
- **Таблица `staff_branch_assignments`**: история закрепления сотрудников за филиалами
- **RPC функции**: `hold_slot`, `confirm_booking`, `get_free_slots_service_day_v2`

## 2. 💰 Финансовая система

### Что это?

Комплексная система управления финансами сотрудников, которая позволяет:
- Отслеживать смены сотрудников
- Рассчитывать зарплаты на основе процентов и гарантий
- Ведти учет клиентов и услуг
- Анализировать финансовую статистику

### Основные возможности

#### Для сотрудников (Staff Cabinet):
- **Открытие/закрытие смены**: начало и завершение рабочего дня
- **Учет клиентов**: добавление клиентов "с улицы" и из записей
- **Расчет зарплаты в реальном времени**: 
  - Базовая доля от выручки (процент мастера/салона)
  - Гарантированная оплата (если указана почасовая ставка)
  - Доплата (topup) при превышении гарантии
- **Статистика**: просмотр доходов за день/месяц/год
- **История смен**: просмотр всех прошлых смен

#### Для бизнеса (Dashboard):
- **Просмотр финансов сотрудников**: мониторинг доходов всех сотрудников
- **Статистика по филиалам**: агрегированные данные по филиалам
- **Управление настройками**: установка процентов и почасовых ставок
- **Аналитика**: графики и отчеты по финансовым показателям

### Технические особенности

- **Единый доменный слой** (`financeDomain`): централизованная логика расчетов
- **Транзакции**: все операции обёрнуты в транзакции для целостности данных
- **Агрегированные статистики**: предрасчитанные дневные/месячные агрегаты
- **Логирование операций**: полный аудит всех финансовых операций
- **Метрики API**: отслеживание производительности и ошибок

### Файлы и компоненты

```
apps/web/src/app/
├── staff/finance/         # Финансы сотрудника
│   ├── components/        # UI компоненты
│   ├── hooks/             # React hooks
│   └── services/          # Сервисный слой
├── dashboard/staff/[id]/finance/  # Финансы сотрудника (для менеджера)
└── dashboard/finance/     # Общая финансовая статистика
```

### API Endpoints

- `/api/staff/finance` — получение финансовых данных
- `/api/staff/shift/open` — открытие смены
- `/api/staff/shift/close` — закрытие смены
- `/api/staff/shift/items` — сохранение списка клиентов

### База данных

- **Таблица `staff_shifts`**: смены сотрудников
- **Таблица `staff_shift_items`**: клиенты в смене
- **Таблица `staff_finance_daily_aggregates`**: предрасчитанные агрегаты
- **Таблица `staff_finance_operation_logs`**: логи операций
- **Таблица `api_request_metrics`**: метрики API
- **RPC функции**: `open_staff_shift_safe`, `close_staff_shift_safe`, `save_shift_items_safe`

### Формулы расчета

- **Базовая доля мастера**: `(totalAmount - totalConsumables) * percentMaster / 100`
- **Базовая доля салона**: `totalConsumables + (totalAmount - totalConsumables) * percentSalon / 100`
- **Гарантированная сумма**: `hoursWorked * hourlyRate` (если указана ставка)
- **Доплата (topup)**: `max(0, guaranteedAmount - baseMasterShare)`
- **Финальная доля мастера**: `max(guaranteedAmount, baseMasterShare)`
- **Финальная доля салона**: `max(0, baseSalonShare - topupAmount)`

## Связь между продуктами

### Интеграция

1. **Клиенты из записей в смене**:
   - При закрытии смены записи со статусом `paid` автоматически добавляются в смену
   - Сотрудник может видеть клиентов из записей и добавлять их вручную

2. **Финансовые данные из записей**:
   - Суммы услуг из записей учитываются при расчете зарплаты
   - Статистика включает как записи, так и клиентов "с улицы"

3. **Единая система учета**:
   - Все клиенты учитываются в финансовой системе
   - История посещений доступна и в бронированиях, и в финансах

## Ценность для бизнеса

### Система бронирования
- ✅ **Автоматизация записи**: клиенты записываются сами, без звонков
- ✅ **Снижение no-show**: уведомления напоминают о записях
- ✅ **Увеличение конверсии**: удобный процесс бронирования
- ✅ **Управление нагрузкой**: контроль загруженности сотрудников

### Финансовая система
- ✅ **Прозрачность расчетов**: сотрудники видят свой доход в реальном времени
- ✅ **Автоматизация расчетов**: нет необходимости считать зарплаты вручную
- ✅ **Аналитика**: понимание финансовых показателей бизнеса
- ✅ **Учет всех доходов**: и записи, и клиенты "с улицы"
